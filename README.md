# DOLL.EXE — A Little Universe That Loves You 🎀❤️

A deeply personal, interactive romantic web experience built by **Kulfi**, for his **Doll**.

> "I made you a whole universe, Doll. But I'd still choose wherever you are."
> — Your Kulfi

## ✨ The Experience

1. **Initializing Her Universe** — a cinematic `DOLL.EXE` boot sequence that searches the stars and finds *MY DOLL 🎀*
2. **Her Little Companion** — meet **Nova**, a blinking, waving, huggable star creature with four comfort experiences:
   🫂 *I Need a Hug* · 💌 *Give Me a Love Letter* · 🌷 *Remind Me How Special I Am* · 🌙 *Take Me Somewhere Peaceful* (with a breathing guide)
3. **The 100 Reasons Machine** — exactly 100 hand-written, unique reasons (no repeats until all 100 are discovered), with a discovery counter, history, and a completion celebration
4. **The Memory Planet** 🔐 — a heart-locked planet guarded by a quiz about one early school morning during COVID… *"Mask lene chaloge?"*
5. **A Secret Letter from Your Kulfi** — unlocked only after the real memory, inside a tiny observatory
6. **The Ending That Isn't an Ending** — stars gather into a glowing heart constellation, a giant hug, and a universe that stays open for revisits

Plus: 5 hidden Easter eggs (the moon, a tiny heart, a special star, poking Nova five times, and her occasional whispers), all nicknames woven through (Doll, Sweetu, Wiffey, Cutie, Jaan, Baby Gurl, My World), optional synthesized sound effects (never autoplay), progress saved between visits, reduced-motion support, and a fully responsive, mobile-first design.

## 🛠 Tech

React + TypeScript + Vite · Tailwind CSS v4 · Framer Motion · Lucide icons · WebAudio-synthesized SFX (zero audio files, zero APIs, zero login)

## ▶️ Run it

```bash
npm install
npm run dev      # develop
npm run build    # production build into dist/
npm run preview  # preview the production build
```

Progress (discovered reasons, unlocked memory, read letter, sound preference) is preserved in `localStorage`, so refreshing never breaks the magic.
